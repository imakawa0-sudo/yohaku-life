# 帰宅した住人はどこで傷を休めるか

住居ロードマップH9は、遠出して傷を負った人が帰った後の居場所と、同居する仲間の過ごし方を扱う。H0で挙げた「自分の部屋で静養する」「共有設備の近くで支え合う」という暮らしを比べるため、一人の帰宅時点から行動を分けて試した。[住居ロードマップ](https://app.notion.com/p/42111141cb3681d98e7bf16736f536fd)・[療養と支援の設計場面](superpowers/specs/2026-11-23-housing-h0-h1-design.md)

## これまでの療養と寝床

二人が森から峠へ74分かけて移動し、探索で出会った危険に対処した。負傷38または76になった時点から、もう一人が115分かけて自宅へ付き添った。二人は居間の入口に着き、負傷はそれぞれ帰路を出発したときの値のままだった。以下の「負傷」はゲーム内の数値で、低いほど回復している。

| 帰還時の負傷 | 行動 | 所要時間 | 終了時の負傷 |
| ---: | --- | ---: | ---: |
| 38 | 居間の入口で「傷をいたわって休む」 | 65分 | 26 |
| 38 | 居間のむしろの隣まで歩いてから、同じ療養を頼む | 移動2分＋65分 | 26 |
| 38 | 寝室のむしろの隣まで歩いてから、同じ療養を頼む | 移動6分＋65分 | 26 |
| 76 | 居間の入口で「傷をいたわって休む」 | 65分 | 64 |
| 76 | 休息欲求の行動で寝室のむしろに寝る | 移動6分＋睡眠85分 | 74 |

帰宅前の峠でも、その場での療養は65分で行えた。帰宅後に自分でむしろの隣へ移動しても、むしろ自体は空いていて、ほかの住人がそこへ寝に来る。入室許可があれば、仲間専用の寝床のそばでも同じ療養ができる。負傷76の住人には、寝具のそばまで自分で歩く室内移動を指示できなかった。

同じ家で、仲間が近いむしろを希望しているとき、そこに先客が寝ていれば、仲間の休息は近いむしろでの87分から、遠いむしろでの91分へ延びた。この差を踏まえ、帰宅後の療養でも、一人が寝床を確保して使う選択と、仲間に寝床を空けておく選択を比べることにした。

## 寝床を使って療養する

住人の「傷をいたわって休む」で「傷を休める場所」を選ぶ。「今いる場所で休む」ならその場で65分間休む。自宅の寝台やむしろを選んで指示すると、住人がその寝床を予約し、隣まで歩いてから65分間使う。本人用または共有の寝床が対象。移動と療養の途中で中止すると予約を解き、完了時の回復は受け取らない。移動区間にいる場合は区間を出てから中止する。重い傷がある住人も、選んだ寝床の利用位置にすでにいれば新しく歩かずに使える。

| 帰宅後、負傷38の人に頼んだこと | 本人の療養終了 | 仲間の睡眠終了 | 仲間が本人の場所へ着き、手当てを終えるまで |
| --- | ---: | ---: | ---: |
| 入口でそのまま療養 | 帰宅から65分 | 87分 | 121分 |
| 居間の近いむしろで療養 | 67分 | 91分 | 131分 |
| 寝室の遠いむしろで療養 | 71分 | 87分 | 127分 |
| 本人専用にした寝室のむしろで療養 | 71分 | 87分 | 127分 |

どの選択でも療養で負傷38から26へ下がり、同じ仲間が32分かけて手当てを終えると1になった。近い寝床を本人に譲ると、仲間は寝床を変えた後、起きてから本人のそばまで8分歩いた。予約・他人の専用寝床・閉じた利用条件などを含む9条件と、移動・利用途中の保存再開も比較した。[再現用の比較脚本](../scripts/compare-rescue-recovery.mts)
