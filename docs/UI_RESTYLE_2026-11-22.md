### アイコンが崩れて見えた原因と修正

元の人物Canvasは48×56ドット。目・眼鏡・髪などに1ドットの描写がある。一覧ではPC30×35px、スマートフォン24×28pxに縮小し、画像自体に1pxの枠線を付けていた。`border-box` のため実際の絵の領域は28×33px／22×26pxとなり、1ドットの線が消えることに加えて、縦横の倍率も揃わなかった。作成画面の26×26pxの丸いアイコンも縮小と切り取りを組み合わせていた。

| 表示場所 | 調整後 |
| --- | --- |
| 暮らしの住民一覧・作成画面の住民一覧 | 40×40pxの枠に、48×56pxの元絵を等倍で表示。左上を1pxずつずらし、顔と頭部を中心に切り取る。 |
| アイコンの枠 | 画像領域を削るborderを外し、枠の外側に1pxのshadowを置く。角丸は3px。 |
| 詳細プロフィール | 絵を96×112pxの整数2倍に固定。大きなアーチ形の切り取りをやめ、角丸3pxで全体を表示する。 |
| 開始画面の人物プレビュー | 48×56pxの等倍に固定し、横並びで縮まないようにする。 |
| スマートフォンの住民カード | 顔と名前の領域を確保するため幅130px。狭い画面の住民一覧は既存の横送りを使う。 |

長髪の毛先や服全体は詳細プロフィールで確認する。この表示調整の段階では人物の描き直しは行わず、`PixelArt.tsx` と `pixelFigure.ts` は基準時点からバイト単位で同一だった。後続の原画修正は冒頭と別文書に記録する。風景・全身の立ち絵・外見設定の定義・保存・ゲームシステムは引き続き変更対象に含めない。

今回のソース差分は `ReformApp.tsx`、`reform.css`、`life.css`、`people.css` の4ファイル。比較用の6人は髪5種・肌5色・年齢3段階・丸眼鏡などを含み、同じ元絵を以前の縮小表示と改善後の表示で並べて確認する。実際の画面と自動テストの結果は [PLAYTEST.md](PLAYTEST.md) の同日追加記録にまとめる。
