# H5a：一室の寒さ対策

確認日：2026年11月26日（台湾時間）。[設計](superpowers/specs/2026-11-26-room-insulation-design.md)・[実装計画](superpowers/plans/2026-11-26-room-insulation.md)・[最新の引き継ぎ](DEVELOPMENT_HANDOFF.md)。

## 今回選んだ範囲

住まいの一室を選び、木材1を取り置き、住人が室内へ運び、合計30分施工する。完成後は、その部屋に実際にいる間だけ、初霜による余分な疲れを防ぐ。技能制限は設けない。初期の裏庭は屋外として対象外にする。具体的な材料量・時間は今回の試作の開発判断であり、参考作品から転載した値ではない。

施工は既存の増築と同じ仕組みを使う。指示や計画では時間を進めず、実際の移動と作業で時計を使う。中断した作業は別の住人へ引き継げる。取消した木材は床や運搬中の束として残り、供給口へ戻す。完成記録から部屋の対策済み状態を読み取るため、保存に別の保温フラグを重ねない。

無対策と、一室への小さな投資、技能が育ってからの家全体の断熱雨戸を比較できる形を選んだ。寝室を整えて長く休む、食事・交流のある居間を整える、対策済みの増築室に設備をまとめる、といった用途の違いを既存の家具指定・優先寝床・共同活動へ結び付ける。

## 実装で守る境界

- **所在：** その1分の開始位置で判定する。行き先や寝床の予約だけでは効果がない。到着の1分を暖室で過ごしたことにしない。
- **旧保存：** 工事の `kind` 省略は従来の増築。正確な住居内位置がない旧人物に、一室の効果を推測して付けない。
- **既存の全体改修：** 木材3、技能5または木工専門化という条件と、自宅の庭を含む従来の効果範囲を保持する。住居の移動を使うゲームで、地域移動中も出発地が自宅のまま残るため防寒が効いていた境界は修正する。
- **材料：** 増築は広さによる木材（標準4×3は6、広め4×4は10）・一室対策1を種類ごとに保存検証する。二重予約、取消時の即時増殖、完成後の再消費を防ぐ。
- **部屋：** 寒さ対策では部屋も部屋番号も増やさない。完成後の家具変更や同じ部屋の拡張を妨げない。屋根や面積ごとの費用は未実装。
- **履歴：** 後から建った部屋を先に保温したことになる保存や、同じ部屋への重複完成を拒否する。家全体が対策済みになっても、それまでの一室工事・履歴を失わせない。

## 比較・検証と結果

### 同条件の本体比較

初霜前後の旧本体52条件・3,088分を先に測り、正規の施工で寝室を対策した本体で追加8条件・530分を比較した。固定したソースを一分ずつ進め、全測定で保存状態の検証と、消耗式から独立に計算した期待値が一致した。人物・暦・欲求を比較用にそろえた合成条件であり、初霜まで通常生活した結果ではない。

開始体力90、初霜後の60分。寝室・居間は待機、地域移動は移動60分であり、行動の異なる行を直接比較しない。

| 場所・体質 | 無対策の終了体力 | 寝室だけ対策した終了体力 | 差 |
| --- | ---: | ---: | ---: |
| 寝室・標準 | 83.16 | 84.30 | +1.14 |
| 寝室・寒さに弱い | 80.88 | 84.30 | +3.42 |
| 居間・寒さに弱い | 80.88 | 80.88 | 0 |
| 到着済みの屋外・寒さに弱い | 80.88 | 80.88 | 0 |
| 地域移動中・寒さに弱い | 76.776 | 76.776 | 0 |

寝室内の値は、旧本体で全体断熱が有効だった室内の値と一致する。新たな一室対策では、効果の範囲が対象室に限定される。地域移動中にも全体断熱が残っていた旧挙動は保存すべき期待値にせず、位置に関する不具合として修正・回帰試験した。

寒さに弱い人物が体力30から寝室のむしろを85分使う比較では、無対策87.124、寝室対策88.5775となった。完了時の回復はどちらも61で、差1.4535は利用中の消耗が減った分。体力90から始める旧比較は全条件が100に達し、最終値だけでは差が隠れた。対策の価値を、回復量が増える効果と説明しない。
