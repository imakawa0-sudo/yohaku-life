# Canvaによる人物原画・レビュー候補16点

更新日：2026-11-23（Asia/Taipei）。

**このフォルダは制作途中のレビュー候補と再現資料です。ゲーム本体には適用していません。** Canvaの利用枠上限に達したため、新たな生成を止め、取得済みの原画と最後の候補選択を保存しています。未完成の人物を完成品として扱わないでください。

## ユーザーが求めているもの

初回試作の画風を保ち、元の全員の特徴・髪型を反映すること。人物の身体の感じと元の姿勢も維持します。初回試作で採用されたのは**絵柄**であり、そこに描かれた別の人物設定ではありません。ユーザーの原文とCanvaの生成記録は [canva-provenance.json](canva-provenance.json) に保存しています。

人物設定の正本は [original-appearance.json](original-appearance.json) の `appearance` です。これは元のゲーム参照から取得した設定で、Canvaの画像内説明から作った設定ではありません。

**Canvaが原画内に書いた名前・性別・年齢・人物説明は採用しません。** `detail-C` は上段中央のCの画像だけ、`detail-Kaya` は左上のカヤの画像だけを使います。MEI、HAYATOなどの新規人物や、`detail-F` に書かれたA〜Fの改変設定はゲームへ取り込みません。元設定を保持していることと、候補画像の見た目がその設定を満たすことは別の判定です。

## サイズ変換の意味と限界

主原画はCanva PNGから明示的に切り出した**原寸crop**です。胸像は192×224・96×112・48×56、全身は104×240・26×60を、それぞれ原寸cropから直接、最近傍補間で作ります。48×56を大きくして詳細画像を作る方法ではありません。

縦横比を維持して指定枠内へ収め、足りない部分だけを透明な余白にします。元画像はRGBの不透明背景を含み、その背景は残ります。したがって、この変換を背景透過・人物の切り抜き・目や衣服の描き直しが完了したものとして扱えません。

細部を保てるかはサイズごとに異なります。縮小結果の見た目とゲーム内での見え方は別に確認する必要があります。今回の保存はゲームへの反映や実際のゲーム試遊の完了を意味しません。

### 変換の再現

Python 3とPillowが必要です。このREADMEがあるフォルダを作業ディレクトリとして実行します。出力先は既存でないディレクトリを指定してください。

```bash
python review-export/prepare_game_art.py \
  --cells review-export/crop-plan.json \
  --source-root review-export \
  --output /tmp/yohaku-canva-review-reproduction
```

`--check-only` を追加すると入力の寸法・ハッシュ・座標を確認するだけで、出力画像は作りません。再現用計画は候補に使う4原画だけを参照します。初回の画風見本と不採用のFは、履歴として同じ `sources/` に保持しています。

## 現行ゲームとの関係

現行の人物は `drawPortrait`（48×56）と `drawWalker`（26×60）で生成されます。顔・肌・髪・年齢・体格・特徴・服・染色などを組み合わせる仕組みです。この16条件は代表見本であり、全ての外見の組み合わせを網羅した置換用画像集ではありません。

この作業で `src/`、ゲームの保存形式、既存の本体HTMLは変更していません。人物ごとの未完成点、背景の扱い、外見の選択肢を維持する実装を解決してから、別の変更としてゲームへ組み込む必要があります。
