# 『余白の暮らし』人物原画 — ChatGPT画像生成での続き

更新：2026年11月23日（台湾時間）

**Canvaの利用上限で残っていた人物原画を、ChatGPTの画像生成で制作したセットです。15点の独立原画を、16項目の透過PNGとして保存しています。** AとGは同じ設定のため、同じ画像をそのまま複製しています。

原寸での外見・画風・背景透過を確認しました。現行ゲームへの組み込み、ゲームサイズへの変換、Sitesへの公開は別工程です。

**GitHub保存用の原画セットです。** `main` の `docs/design/chatgpt-characters-20261123/` に、25ファイル（最終原画16枚・履歴画像1枚・確認資料8ファイル）を収めています。画像は生成結果から変更せず、ファイル内容を表すGit blobの値を照合しています。ゲームへの組み込みとSitesへの公開は別工程です。

## 引き継いだ基準

人物の外見は、[前回の元設定](../canva-characters-20261123/original-appearance.json)を基準にしています。初回Canva試作から採用するのは画風であり、生成画像が付けた名前・性別・年齢・人物説明は設定に加えていません。

全身は公開57の約5頭身を基準にした、少し可愛さのある成人の立ち姿です。スイは初回生成が頭身高めだったため、髷を除いても約5頭身になるよう追加修正し、肩・胴・腕・脚の厚みも調整しました。カヤの標準体格とスイのがっしりした体格を、姿勢・顔立ちと合わせて目視確認しています。

衣装比較の基準人物はAとは別条件です。衣装側は桃肌・成人・丸く開いた目、A側は象牙系の肌・若年・穏やかな細い目です。両者を同じ顔へ統一していません。

## 確認したことと、次の工程

全16ファイルが実際の透明度を持つRGBAのPNGで、紙色の矩形背景はありません。生成画像の外周にはほぼ透明な色画素が残ります。完全に透明／不透明の2値だけで構成された画像ではなく、完全なピクセル配置の同一性も保証していません。AとGの同一性はファイルのハッシュで確認しています。

今回完了したのは**原画制作と原寸での確認**です。胸像48×56・96×112・192×224、全身26×60・104×240への変換は、このセットには含まれていません。変換時は目・傷・そばかす・年齢感・輪郭差が小さい表示でも読めるか確認します。

現行の `src/reform/pixelFigure.ts` は、顔・肌・髪・髪色・年齢・体格・目・特徴・服・染色を組み合わせて人物を描きます。この16項目は代表的な確認条件で、全ての外見の組み合わせを置き換える素材集ではありません。キャラクター作成の選択肢を保つ実装と、実画面での確認は次の工程です。

`runtime_integrated` と `production_ready` は `false` です。GitHubへの制作データ保存を、ゲーム反映やSites公開と混同しません。以前のCanva候補と中断記録は、制作経緯としてそのまま残しています。
