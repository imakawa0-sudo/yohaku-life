# 一室に住むことと、家具を使うこと

アオ・ミドリ・アカの三人が一軒の家で暮らす。ミドリには寝室の寝台を使ってほしい。それだけなら、すでに部屋の入室許可と専用寝床で設定できる。今回調べたのは、アオが寝室を提供し、ミドリがそこを自室として選んだとき、町から帰る日の行動にどんな違いが生まれるかだ。[住居ロードマップの「所有・世帯・入退居」](https://app.notion.com/p/42111141cb3681d98e7bf16736f536fd)

## 入居を足す前の三日間

同じ三人・同じ地形から、部屋も寝床も共有、寝床だけミドリ専用、寝室も寝床もミドリ専用、寝室の利用者はアオとアカ、ミドリが町に滞在、の五条件で各72ゲーム時間進めた。森の家から町へは片道38分。帰宅する四条件・各3日の計12回で、ミドリはすべて居間の入口に着いた。

- ミドリが寝室を使える条件では、帰宅後に寝台での休息を終えるまで3日とも61分だった。入れない条件では居間のむしろを使い88分。町に留まった条件では現地で90分だった。
- アオが居間の入口で待っている同じ帰宅場面から、ミドリを寝室の入口まで歩かせると3分かかった。そこから寝台で休めば帰宅から完了までの61分は同じで、かまどへ食べに戻れば22分が28分になった。居間で待つ人とは直接話せなくなった。帰宅してすぐ眠りたい日と、皆と食べたい日とで、自室へ寄る意味が違う。
- 銀貨12から4枚を荷物に移すと共有分が8になり、帰宅時には銀貨12へ戻って携行分が0になった。この一軒の世帯は財布を共有する。同居人同士の家賃を同じ財布でやり取りする方式では、貸す側・借りる側の事情を表せない。

## 一室を提供して実際に住む

「一室の間借り」で、アオが自分が普段利用できる寝室をミドリに申し出る。申し出るだけでは入室許可も寝具の割当も変わらない。ミドリに切り替え、受けるか見送るかを選ぶ。受けると自分の足で居室の入口へ向かい、到着すると入居が成立する。検証した間取りでは3分だった。この操作はプレイヤーがそれぞれの住人に出した指示として扱う。

通常許可をアオだけにしている場合、入居後はアオとミドリが寝室の設備を使える。入居していないアカの権利は増えない。誰かの専用寝床やすでに予約中の家具には、それぞれの利用条件がある。入居に合わせて部屋の通常利用者を上書きせず、退居後はもとの許可が働く。

ミドリは、普段の帰宅後に「共用の玄関で止まる」か「玄関から居室まで歩く」かを選べる。町から帰ると両方とも38分でまず居間の入口に着き、運んだ荷物をここで下ろす。共同備蓄に入らない分は本人の携行品に残り、あとで空きができたら手動で下ろせる。他の住人が取り置きを取り消して戻すための空きも保つ。自室へ向かう設定ならさらに3分歩く。入居した二つの条件をそれぞれ72時間進め、3日とも玄関から寝台までの休息は61分、自室に寄る場合は3分歩いてから58分だった。帰宅時に通路が閉じていれば玄関に残り、その場合の休息は居間のむしろで88分だった。

寝室にいるミドリが退居を選ぶと、居間の入口へ3分歩いて引き渡しを終える。出口が閉じていれば入居を保って寝室に残る。町にいるミドリが退居した場合は、そのまま町にいて、次の帰宅先は通常の玄関になる。申し出への移動を始めて1分で取り消した条件では、すでに進入していた区間を出るまで歩いても入居は発効しなかった。[五つの基準条件と二つの入居条件の再現](../scripts/compare-room-lodging.mts)

## 荷を持ち帰りきれない日の保存

帰宅先に居室を選んでいても、荷物を下ろすのは玄関に着いた一回。木材を4本持って帰り、共有備蓄には2本分の空きしかない場面では2本を積んだまま居室へ向かう。備蓄に空きができたら「木材を荷物から下ろす」を選べる。食事・食材・銀貨にも、すでに誰かが取り置いた分を元へ戻せる空きを残す。

古い保存で、すでに積み込みを予約したのに荷物と棚がともに満杯だった場合は、戻せない品名と数量を共同備蓄に表示する。別の住人がその分を積み直したときや、実際に備蓄を使って空きができたときに精算する。荷重で地域の移動時間が保存可能な範囲を超える場合は、出発する前に理由が表示される。[荷下ろしと保存の試験](../tests/reform-room-lodging.test.ts)・[以前の積み込みと返却の試験](../tests/reform-packing-stock.test.ts)

## 維持を誰に頼めるか

普段はミドリだけが使える寝室で、ミドリが自分で寒さ対策をすると木材1、搬入6分、施工30分。終わってからミドリが基本木工をすると69分目に木工が終わった。普段の入室許可を二人に広げ、アオが同じ工事をする対照では、工事は36分、ミドリの木工は33分で終わった。ミドリの木工経験はいずれも19.5だった。専用のままの寝室にはアオが材料を運べなかった。この比較を、入居者本人が維持を担うか、提供者へ一件の工事を頼めるようにするかを検討する出発点にする。
