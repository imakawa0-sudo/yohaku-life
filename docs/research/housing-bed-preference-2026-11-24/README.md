# 住人ごとの優先寝床と、使えない時の代替

2026-11-24（台湾時間）。[一回ごとの家具指定](../housing-room-use-2026-11-24/README.md)に続き、住人が普段使いたい寝床を保存できるようにした。同じ寝床を二人が優先していても、先に一人が予約した時は、もう一人が使える別の寝床を探す。[設計](../../superpowers/specs/2026-11-24-housing-bed-preference-design.md) ／ [実装工程](../../superpowers/plans/2026-11-24-housing-bed-preference.md)

## 遊び方

納品状況：実装・試遊・単体HTMLの保存・Notion更新は完了。GitHubへの反映は自動承認レビューにより保留中で、保存後の読戻しは未実施。[保存結果と再開手順](delivery.md)

1. 「暮らし」で住人を選び、「暮らしと備蓄の方針」を開く。優先する寝床を、部屋・家具・マス位置から選ぶ。「未設定（使える寝床から選ぶ）」で解除できる。
2. 「休息に使う設備」欄が自動の時は、今使う見込みの寝床と移動・利用・合計時間を確認する。優先先が使えない場合はその理由と、実際に向かう別の寝床が表示される。自主休息も同じ条件で選ぶ。
3. 今回だけ特定の寝床を使いたい時は、「休息に使う設備」欄でその家具を指定する。指定した家具が使えない時は理由が出る。この一回の選択と、方針で保存する寝床は独立している。

普通の休息を計画する時点で設定を参照する。移動中や睡眠中に方針を変えても、その時の行き先と予定は続く。外出中も方針を設定でき、適用は次に家で普通の休息を計画する時。野外の休息、負傷時の療養、住居移動を使わない旧保存は従来の扱いとなる。

## 採用の根拠と比較

本棚一台を共有する枝では、スイは先に木工を続け、読書を09:18に完了した。同室に二台を置く枝は08:55、増築室に二台目を置く枝は08:56。木材費と開始位置、先に働いた結果も異なるため、時刻の差を部屋の位置だけには帰せない。[実装前の比較と再現手順](comparison.md) ／ [記録データ](evidence/comparison-baseline.json)

同じ21:33の状態から、優先設定の有無だけを変えて627分進めた。未設定では翌01:56のカヤが近い追加むしろへ、翌02:50のスイが空いていた元のむしろへ向かった。カヤに元のむしろ、スイに追加むしろを設定すると、二人とも20:00に一回指定した寝床を次の自主休息でも選んだ。翌朝08:00の木材22・食事10・食材3・銀貨8は両枝で同じで、カヤの身支度とスイの自由時間には残り分数の差が出た。これは公開プリセットから作った一晩の本体比較。[設定の有無の対照](preference-comparison-notes.md) ／ [記録データ](evidence/preference-comparison.json)

二人が同じ寝床を設定する補助枝では、後から指示された住人が他方を使い、先に利用していた住人が予約を取り消しても、その時の利用を完了してから次の通常休息で優先先へ戻った。日々の選択を保存しつつ、空いている家具を共有できる方式を採用した。[参考作品の一次資料](reference-check.md) ／ [判断の記録](decisions.md)
