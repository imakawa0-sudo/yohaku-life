# H2/H3への受け渡し：一室の計画・資材搬入・施工

2026-11-24（台湾時間）。H1-Cと並行して具体化した**後続の設計案**。以下の工事機能は未実装で、試遊結果ではない。各段階の着手時に参考作品の調査を更新し、実装した共同活動との接続も再確認する。

## 次に通す一周

「隣に一室を計画する → 木材を現地で取り置く → 住民が実際に運ぶ → 別の住民でも施工できる → 完成した部屋へ入る」を、同じ人物・時計・位置・物資・保存で成立させる。

H1-Cは、誰が実際に席へ着いて何分参加したかを生活へ接続する工程だった。H2/H3では、どこに資材があり、誰が運び、どこまで建てたかを接続する。これにより、留守宅の生産、人手の配分、部屋への投資、冒険へ出る準備が影響し合う。H4の招待・個性・生活時間すべての完成を、建築着手の条件にはしない。

## 役割と会計の境界

計画は、名前・接続先・仮置き場・必要資材などの追加差分を保持する。計画を置いた時点では部屋を実際の経路へ公開せず、時計や在庫も進めない。資材不足でも計画は残せる。

初回の供給元には、既存の共有木材を工事用に取り出す自宅内の受け口を一つ定義する。例えば居間入口を使うが、旧木材が過去からその床に置かれていたことにはしない。明示した取り置きで自由在庫から一束へ移し、一束の材料IDを空間物品と結ぶ。本人のcargo、Task.reserved.wood、仮置き在庫の別コピーへ同時加算しない。

仮置き場は、完成前から存在する接続先の床を使う。供給元と仮置き場が異なるため、取りに行く・持つ・運ぶ・置くことを実際の時間と位置で確認できる。資材を取り置いた人、運んだ人、施工した人を同一人物に固定しない。

施工は現地に到着し、作業の許可と身体条件を満たす時間だけ進める。通行できることと、材を扱う・施工する権限は別に検証する。許可を失った住民が退室できることを、その部屋で施工できる根拠にはしない。

完成時には、その時点の家へ追加差分を適用し直す。形状と現役の位置・予約を検証した上で、搬入済みの一束を一回消費し、新室・接続・完成記録・日誌を一つの更新で反映する。既存の即時編集からは安全検査を共有し、引落しと日誌を重複して呼ばない。検査に通らない場合は完成反映を待ち、材料と施工済み時間を保持して理由を表示する。

開始前の家づくり、既存保存の完成した家、開始後の新室施工は別の入口にする。新室追加を工事へ切り替える場合は、画面だけでなく本体の即時編集でも新室追加を区別する。工事完了の入口は検証済みの計画IDから差分を作り、任意の間取りを無料で反映する入口にしない。

## 中断で物が消えないこと

| 場面 | 残すものと次の行動 |
| --- | --- |
| 搬入の割当が最初から不可能 | 人物・現在の予定・資材・IDを部分変更しない。計画を残し、通路や担当を選び直す。 |
| 移動中の通路閉鎖・許可取消 | 進入済みの区間は終点まで進む。次の区間へ進めない人は荷と予約を保持して待つか、安全な床へ下ろして離脱する。 |
| 人物だけを仕事から外す | 作業担当の予約を解き、計画と材と施工済み時間は残す。同じ現物を別の人が引き継げる。 |
| 工事全体を取り消す | 未調達なら終了。元の受け口で未使用なら予約を解いて自由在庫へ一回戻す。持ち出した材は実際の床に残し、受け口まで運び戻して初めて自由在庫へ合流する。 |
| 危険・重傷で作業できなくなる | 新しい持上げ・区間進入・施工を止め、安全退出後に担当を解放する。別の健康な住民の生活は続く。 |
| 施工中に別の家具を編集する | 完成時の追加差分から再検証し、無関係な編集を古いプレビューで巻き戻さない。 |

検算する資源は「自由な備蓄＋一意の残存工事材＋施工で消費した分」。既存の生産・売買による増減と区別し、取消・再開・読込みでこの総数が増えないことを確かめる。

## 保存と最初の受入条件

工事情報は省略可能な拡張として旧保存と区別する。読込みや表示では位置・資材を移さない。現在のgameだけに計画と進捗を加え、最初の朝originを遡って書き換えない。旧作業の予約元・残時間も再計算しない。現在の保存形式を維持できるかは、実装時に実際の移行候補で判断する。

材料IDと空間物品の双方向対応、所在の重複、運搬者と注文、工事への取り置き、搬入済み条件、施工残り、完成・取消後の残材を検証する。破損を読込み時に補って正常に見せない。古いHTMLが新しい工事データを読めることは保証せず、新版が旧保存を読める互換と分ける。

最初の受入れは通常の作成画面から、一室を計画し、二人が搬入と施工を分担し、完成後にその部屋へ移る経路。併せて、拾う前／持ち運ぶ途中／仮置き後／施工途中／完成反映待ちで保存・取消・再開を確認する。自由在庫が0でもすでに運んだ材で完成できること、別の家具編集でその材を使えないこと、320/390pxで材の場所と再開方法が読めることを確かめる。
