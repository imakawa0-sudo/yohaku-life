# 住居H2/H3：一室を計画し、運び、建てて使う

2026-11-24（台湾時間）。H1-Cの共同活動に続き、家を広げるための材料と人手を、普段の暮らしと同じ場所・時間で扱う。

## 今回の一周

住まいの工事欄で部屋の名前、接続する部屋、資材を集める床を選ぶ。計画を置いただけでは、間取りも時計も木材の数も変わらない。木材が足りないときも計画は残せる。

木材を取り置くと、自由に使える備蓄から6を分け、居間の供給口に一つの束を置く。運搬の担当者はそこへ歩き、束を持ち、予定の床まで運ぶ。別の住人を施工担当に選ぶこともできる。担当は予定のない住人から選び、別の仕事をしている人は「暮らし」でその予定を取り消してから指示する。施工は現場で実際に作業した分だけ進み、移動や待機には工事の進捗を付けない。

30分の施工が終わると、その時点の間取りへ4×3の空室と接続を加える。工事中に行った無関係な家具移動は保つ。完成した部屋へ歩き、既存の家具を配置して生活に使える。

## 途中で予定を変える

担当を外しても、既に作業した分は残る。7分施工した後は、別の住人が残り23分を引き継ぐ。通路の途中では、その区間を抜けてから担当を外す。工事全体を取り消し、担当の解除が済むと、供給口に残っている束は備蓄に空きがあれば戻る。持ち出した束は実際の床に残るため、回収担当を選んで供給口へ運び戻す。

通路が閉じているときは担当と木材を保って待ち、通路を開けると進める。取り扱う部屋の利用許可が失われたときや、身体の条件を満たさなくなったときは、安全に担当を外す。条件を戻した後は、改めて担当を選ぶ。

備蓄が上限に達して木材を戻せない場合は、束を供給口に残す。自由な木材を使って空きを作り、「供給口の木材を備蓄に戻す」で返却できる。

## 試作の範囲

初回値は4×3、木材6、実作業30分、未解決の工事1件。取り消した木材の回収待ちも1件に含む。数値は試作の調整対象であり、完成版の建築規模や同時工事件数の上限を確定するものではない。

部屋の名前は用途を自動で決めない。生活上の使い道は、配置した家具と実際の行動につながる。寝室・工房・収納への投資の比較、倉庫と材料の取り出し場所、自動の仕事分担は後続の接続として残る。

## 保存と旧方式

元の朝と既存の保存枠を保ち、工事の途中、実位置、担当、残り時間を保存する。住居の移動をまだ使っていない暮らしは、手帳の既存の分岐操作から新しい方式を選ぶ。読込みや画面を開いたことだけで、古い行動の位置や過去の運搬を作らない。

Game1、手帳形式2、保存キーv2、書出し形式1/2、住居形式1は維持し、工事の追加記録を厳密に確認する。新しい工事を含む保存を古いHTMLへ戻して読む互換性は対象外。
