# 家具を選んで使う：行き先と時間を指示前に確かめる

2026-11-24（台湾時間）。[H2/H3の一室工事](../housing-h2h3-2026-11-24/README.md)に続き、建てた部屋へ家具を置いた後の使い分けを扱う。生活行動で使う家具を選び、そこまで歩く時間と利用する時間を確かめてから指示できるようにする。[設計](../../superpowers/specs/2026-11-24-housing-room-use-design.md) ／ [実装工程](../../superpowers/plans/2026-11-24-housing-room-use.md)

## 操作と対象

「暮らし」で住人を選び、生活の行動欄から使う設備を選ぶ。対象は、自宅で住居の移動を使っている暮らしの食事、用足し、身支度、休息、交流、楽しみの6用途。

既定の「自動（移動と利用が短い設備）」は、従来の経路・空席・利用許可の規則で行き先を選ぶ。特定の家具を使わせたい場合は、部屋名、家具名、家具のマス位置から選ぶ。同名の部屋がある場合は「同名の1室目」などを添え、同じ種類の家具を同じ座標へ置いていても識別できる。選択肢と自動・指定の予告に同じ表記を使う。複数席のある家具では、その家具の到達できる空き席を既存の規則で決める。

行動の下には、選ばれる部屋と家具、現在地からの移動分、実際の利用分、合計分を表示する。食事では取り置く食事1も示す。「現在の見込み」はその時点の予測で、後から通路を閉じた場合などの待機時間は含まない。選ぶことや予告を見ることでは時計を進めず、行動を指示してから共通の時計で歩行・待機・利用を進める。

## 使えなくなった時の扱い

選んだ家具が予約済み、通路閉鎖、入室許可不足などで使えない時は理由を表示し、その行動を無効にする。選択欄から別の家具や自動を選び直せる。時間送りや他の住人の予約変更があれば、同じ選択に対して現在の条件を調べ直す。

同じ住人・保存枠では「住まい」「地域」「手帳」への画面切替後も未確定の選択を保つ。選んだ家具を取り外した場合は「選んだ設備がありません」と表示して実行を止める。住人または保存枠を実際に切り替えると、未確定の選択は自動へ戻る。これらは画面内の一時的な選択で、恒久的な寝床や私物の割当とは別の機能である。[判断6](decisions.md)

外出中と、住居の移動へ切り替えていない旧方式では従来の行動欄を使う。家具を指定したことを理由に、危険、負傷、移動区間途中、入室許可の制約を回避しない。

## 増築と既存室を比べて決めたこと

変更前の公開関数で、同じ「木工の二人」の朝から、同じ本棚を増築室と既存の居間に置く二つの暮らしを比較した。両方とも初日08:36に、居間入口のカヤへ読書を指示する。本棚の種類と部屋内の座標、カヤの欲求をそろえた。[条件と全結果](comparison.md)

| 実測 | 増築した読書室 | 既存の居間 |
| --- | --- | --- |
| 工事・家具の木材 | 工事6＋本棚4 | 本棚4 |
| 読書までの移動 | 7分 | 1分 |
| 待機・実利用 | 待機0分・利用14分 | 同じ |
| 合計・完了時刻 | 21分・08:57 | 15分・08:51 |
| 読書の結果 | 楽しみ100、「静かな自由時間」+6 | 同じ |
| 翌朝08:00の自由な木材 | 12 | 20 |

この条件では、既存の居間でも同じ読書効果を得られ、移動が6分短かった。翌朝の木材差8には、工事で使った6と、工事をしなかったスイが木工で得た2が含まれる。一組・一日・一つの配置の結果であり、増築一般の優劣や複数人の混雑を決める値ではない。

上の時間は、本棚を両方の部屋の3列1行へ置いた比較の値である。通常の「この部屋に置く」で選ばれる位置が違えば、同じ部屋・家具でも移動分は変わる。画面での試遊は、その時に表示された家具の座標と利用者の位置を記録して比較する。

さらに二つの本棚を同じ暮らしに置くと、従来の自動は合計15分の居間を選び、合計21分の読書室を直接指定する入力がなかった。今回はここを接続し、配置や使い分けの判断に必要な行き先と時間を表示する。部屋の名前に性能を付けて増築の利益を作る変更は含まない。新しい本体で自動の比較を再実行し、追加された予告情報以外の記録が一致した。[再比較](evidence/auto-comparison-after-core.json)

## 共通の行動と保存

入力用の `home-use` と家具IDを受け取り、開始時には既存の `need` 作業へ変換する。欲求の種類、部屋、家具の使用枠、実位置・移動指示は従来の予定と同じ項目に保存する。指示用の名前を新しい保存作業種として残したり、未確定の選択を保存形式に追加したりしない。

移動中・利用中の書出しと再読込み、元の朝、予約、食事の取り置き・取消時の一度だけの返却、完了時の効果は既存の処理を通す。Game1、手帳形式2、保存キーv2、書出し形式1/2、住居形式1を維持する。[本体の実装](../../../src/reform/sim.ts) ／ [家具・席と経路](../../../src/reform/housing/bridge.ts)
