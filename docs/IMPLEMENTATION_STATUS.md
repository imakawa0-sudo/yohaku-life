# 学習後の提案・合意と実装の対応

## H7の一室の入退居

一室の申し出・承諾・見送り、実際の入居移動、通常帰宅後の行き先選択、本人による退居を追加した。入居者は居室の設備を使い、同居人を集まりに招ける。普段の利用者と寝床ごとの割当は別々に保持する。家計は世帯で共有し、地域からの荷物は共用玄関で一度だけ戻す。[保存・帰宅・退居の比較](HOUSING_ROOM_LODGING.md)

## H4・H7の一回の招待

入室が制限された部屋で、普段入れる人が、同居人一人に今回の集まりの席を用意できる。招待の有効期間、普段の利用許可、席や食事の予約、実際の同席を分けて扱う。途中の離脱・取消、返却待ちの食事と古い保存の継続も試した。[操作と比較](HOUSING_GATHERING_GUEST.md)

## H9の帰還後の療養

「傷をいたわって休む」で、その場か自宅の一台の寝床を選べる。寝床を指定すると利用位置まで歩き、到着してから65分間療養する。直接指示、寝床の割当、利用予約、仲間が同じ床で行う手当てをつないだ。重い傷での移動制限と、従来の野外・自主療養も確認した。[帰還・療養・手当ての比較](HOUSING_RECOVERY_BED.md)

## H3の解体と再利用

設置済みの木工台に担当者が歩き、解体後に木材一本が元の床へ残る。拾い手が供給口まで届けると備蓄が一本増える。作業途中・運搬途中での中止、引き継ぎ、備蓄上限、既存の家具や隣の予約の保護を扱う。[判断と実測](HOUSING_WORKBENCH_RECOVERY.md)

## H4：部屋を共有して寝床だけを専用にする

住人の優先寝床、部屋の入室者、寝床を使える人を別々に指定できる。三人の同居で、読書や通行を保ったまま、一人の寝床を空けておく選択を比較した。[設計・8条件の比較](HOUSING_ASSIGNED_BED.md)

## H2の一室増築に二つの広さを追加

4×3（木材6）と4×4（木材10）の一室を設計し、どちらも材料の実搬入・30分の施工で完成する。最初に用意する床と必要資材を選べる。[再現条件と配置の比較](HOUSING_EXTENSION_SIZE.md) 材料を取り置く前なら、同じ計画番号で広さ・部屋名・接続先・仮置き床を見直せる。

## 一室の寒さ対策と滞在時間

初霜前にどの部屋へ投資するかを同じ世帯で比較した。一室の寒さ対策の画面から、昨日と今日に選んだ部屋で各住人が過ごした分数と計測範囲を確認できる。[初霜後3日間の比較と滞在記録](HOUSING_ROOM_STAY.md)

## H6b後の工房比較と基本木工

新版の自宅に任意の木工台（木材3・1席）を置き、基本木工1回の移動先・仕事場として指定できる。既存のその場の仕事と、料理・生活設備・食材補充を併用できる。[木工台の設計と結果](HOUSING_WOODWORK_BENCH.md)
