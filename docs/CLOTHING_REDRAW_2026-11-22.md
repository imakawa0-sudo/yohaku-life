# 旧の体つきを保った衣服の修正

記録日：2026-11-22（Asia/Taipei）

## 最新の指示と採用範囲

衣服の修正中に、ユーザーから「新の方今度は体が変になっている。体の感じは旧のままで、服の違和感だけ直してほしい」と指示を受けた。肩・首・胴体まで描き直した途中案は取り下げ、直前の確定版 `a90b0a67ee5ff5006e4b285ce08f7287f17762ab` の体の描き方へ戻した。

ここでいう「旧」は、この衣服比較の左側に置いた直前の原画である。旧版53のUIや、顔の修正前へ戻す意味ではない。前回の顔・髪の修正は維持する。

ゲームソースの変更は `src/reform/pixelFigure.ts` の `clothing()` 内だけ。共通の肩・首・胴体・袖・陰影は基準版と同じで、服の上に重なる細部だけを修正する。体つきを変える案、新しい白襟・首布を付ける案、配色を置き換える案は採用していない。

| 服装 | 今回の修正 |
| --- | --- |
| 襟つきシャツ | 変更なし。細身・中肉・がっしりの3条件で全画素が基準版と一致。 |
| 仕事着と前掛け | 元の仕事着と体形を維持し、肩ひもを肩の内側に収める。ひもと胸当てのつながり、上辺、ポケットの線を整理。 |
| 巻き襟の上着 | 生成りの色と重なり方向を保ち、胸を横切る明るい縁を少し細くする。 |
| 旅の外套 | 左襟の細かく折れた陰影を整理。外形、右襟、下の服、首元、ボタンは維持。 |

## 比較の基準

- 基準の描画ソースSHA-256：`4720bca847b0e18daeaeb6040d948e198dd86561ce17adaa86f644f73adba5ab`。
- 最終候補の描画ソースSHA-256：`ed6cc890095716c6885f5302aca7fc7ebb9b1ea27144c136221504178d672e17`。
- 4種類の服装 × 3体格の12組を、同じ顔・髪・肌・年齢・目で比較。192×224pxの整数4倍表示と、中肉4組の96×112pxの実表示サイズを使った。
- 担当者は12組を目視。独立した目視レビューはシャツ細身を除く11組で実施した。
- `clothing()` の外側はソースがバイト単位で一致。顔、髪、色の定義、全身立ち絵、ゲームの仕組みはこの修正で変えていない。
- 人物の透明部分を含む輪郭は12組中11組で完全一致。前掛け・細身の1組だけ、旧の肩ひもが体の外へはみ出していた `(36, 42)` の1画素を除去した。これは体の幅や肩の描き方の変更ではない。

この比較は代表12条件の確認であり、全ての外見の組み合わせを確認したものではない。
